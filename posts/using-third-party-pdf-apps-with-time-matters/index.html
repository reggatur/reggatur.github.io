Using Third Party PDF Apps with Time Matters

Date: Aug. 14, 2019    Categories: document management , links

The current paid versions of Adobe Acrobat are expensive. They require annual subscriptions. Third party options now offer very competitive feature sets at much lower cost.

The catch is that you can’t put a TM Save button in third-party software.

Here are some tips for using third party apps with Time Matters.

Install Both Acrobat Reader and Third Party PDF Software

You can have two PDF programs on your computer. Use free Acrobat Reader with its TM Save button to open and save PDF files into Time Matters, linking them to Matters or Contacts or both.

Use your third party software when you need features like redacting text or inserting Bates numbers.

Switch between Acrobat Reader and a Third Party App

You can set the app you use the most as you default app for PDFs. Then when you need to use the other app with a file, right-click on the file and select: Open With. A list of programs that work with PDFs appears. Choose the app you want.

Set the Default App for PDF Files

To set the Default App for PDF Files in Windows 10:

  1. Click the Home button (lower left)

  2. Click: Settings / Apps / Default Apps / Choose default apps by file type

  3. Hover the mouse over the right edge of the window to reveal the scroll bar.

  4. Scroll down to .PDF

  5. If the current app is the one you want, you are all set. If not, click and and select the app you want as your default.
