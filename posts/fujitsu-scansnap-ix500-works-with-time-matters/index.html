Fujitsu ScanSnap iX500 Works with Time Matters

Date: Oct. 14, 2013    Categories: document management , products

The Fujitsu ScanSnap iX500 is now the scanner of choice for law firms. Priced at around $400 (after discounts) including a license for the full version of Adobe Acrobat Standard (sometimes one version behind), it is fast, easy to use and works very well with Time Matters software.

Time Matters puts a TM Save button into supported versions of both free Acrobat Reader and of the paid versions of Adobe Acrobat (Standard and Pro). You can use the TM Save button and any scanner that creates PDF files to save scanned documents.

One Time Matters user was told by a scanner vendor that he could not use the Fujitsu ScanSnap iX500 with Time Matters. That is not true!

You don't need to be concerned about about Time Matters' support for particular scanner hardware. All you need are:

  1. A version of Acrobat or Acrobat Reader that works with Time Matters.
  2. A scanner that can create PDF files.

For example, Time Matters 12 currently supports versions 9, X and XI of Acrobat Reader, Standard and Pro.

You can set the ScanSnap to scan directly to a PDF file. We create a folder named "Scans" in the shared files folder for Time Matters. As you scan documents, they appear on your screen as open PDF documents. Click the TM Save button in the Acrobat window to create a Time Matters Document record and save the document to the correct client and matter folder. This process can be semi-automated using the features for Time Matters Document forms.
