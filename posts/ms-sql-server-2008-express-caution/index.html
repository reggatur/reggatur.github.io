MS SQL Server 2008 Express - Caution!

Date: Mar. 26, 2010    Categories: products , setup , troubleshooting

The standard installation of Time Matters 10 gives you the option to install MS SQL Server 2005 Express. The process has been trouble-free for the large majority of customers. But you may want to put a more recent version, 2008, on your computer.

At this writing, you can install MS SQL Server 2008 Express with SP1, but then you cannot install SQL Server 2008 Management Studio Express , a program that is important for configuring Time Matters 10. Trying to do so generates a compatibility error message and the installation fails. To avoid this problem, you have two options:

  1. Install SQL Server 2008 Management Studio Express first and then install MS SQL Server 2008 Express. It seems backwards, but it works.
  2. Use the Microsoft Web Platform Installer to install both programs together, one after the other. It may still generate an error message, but has been successful.

To install MS SQL Server 2008 Express and SQL Server 2008 Management Studio Express:

Open Microsoft Internet Explorer (not FireFox)

Download the Web Platform Installer from Microsoft__ Click: Get the Web Platform
Press: Run, Run
Click the yellow bar that appears at the top of the window
Press Run
Press Allow
The Web Platform Installer window appears
Uncheck: Install ASP.NET
Click the Web Platform item to the left
In Web Platform,
Starting with "Web Server," click every link that says: Click to remove ...
For Database, click Customize
Select only SQL Server 2008 Express
and SQL Server 2008 Management Studio Express
Click Install
Press: I Accept
Select: Mixed Mode
Enter a password (for sa - the system admin for SQL Server)
Press Continue
If a Compatibility warning appears, select Run Program
Press Finish

Open SQL Server 2008 Management Studio Express from the Start Menu.
