Time Matters Document Name Characters

Date: Aug. 3, 2017    Categories: document creation , document management

Avoid using these characters when naming Documents in MS Word, Excel, WordPerfect, and other programs:

< (less than)

(greater than)
: (colon)
" (double quote)
/ (forward slash)
\ (backslash)
| (vertical bar or pipe)
? (question mark)

  • (asterisk)

These are considered invalid or illegal characters by Time Matters.

When using the TM Save button, any of these characters will be changed to the underscore (_) character. Note that you may use commas and periods.

A minor drawback of commas and periods is that they may cause problems when filenames are used by some other applications, both on the Web and on PCs. For those applications, you may need to save a file without commas or periods.

Typically the setting for document naming by the TM Save button uses the Description field of the Document Form as all or the main part of the Document Name. So if possible, avoid using slashes and other invalid characters.
