Searching with Windows Explorer

Date: Nov. 7, 2013    Categories: Windows

Windows Tip

Windows Explorer, which you can get to quickly by pressing Windows Key and E together, has a Search box in the upper right area for finding files. If your search results are overwhelmingly long, you can narrow your search.

To search for specific files or folders, you can add filters after your search word, for example:

  • smith type:folder (finds all folders with "Smith" or "smith" in the folder name)
  • smith type:pdf (finds all PDF files with with "Smith" or "smith" in the file name)

By starting your search from a folder, you search only the files in that folder and its subfolders.
