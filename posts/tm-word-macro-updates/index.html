TM Word Macro Updates

Date: Mar. 2, 2015    Categories: MS Office , document management

Updated Microsoft Word macros are available for Time Matters. They eliminate the message in Word that says the Lexis VeriSign certificate expired on 1/23/2015.

Download the macro file for your version of Time Matters here:

Time Matters 14
http://support.lexisnexis.com/lndownload/software/TM14_Word.zip

Time Matters 13
http://support.lexisnexis.com/lndownload/software/TM13_Word.zip

Time Matters 12
http://support.lexisnexis.com/lndownload/software/TM12_Word.zip

Time Matters 11
http://support.lexisnexis.com/lndownload/software/TM11_Word.zip

To install the new TM Word Macro:

  1. Close Microsoft Word
  2. Open the downloaded Zip file and copy or extract the file, TMWordAddIn.dotm, to the Time Matters program folder, for example:
    C:\Program Files (x86)\LexisNexis\Time Matters\ or
    C:\Program Files (x86)\LexisNexis\Time Matters13\
  3. In Time Matters, go to Main Menu | File | Setup | General | Workstation Level.
  4. Click External Program Setup or Word Processor Setup
  5. Uncheck the Microsoft Word 2007... box
  6. Click OK
  7. Click External Program Setup or Word Processor Setup again.
  8. Make sure Microsoft Word 2007... is checked and clidk OK.
