Fix for TMSave in Word 2013

Date: Feb. 1, 2016    Categories: MS Office , links

A Microsoft Office update broke the Time Matters Integration in Microsoft Office 2013.

LexisNexis Technical Support has created a work-around for this issue.

  1. Go to support.lexisnexis.com/timematters
  2. In the Search box, enter: 81093 and press Go
  3. Follow the instructions for running a Microsoft Office update.

Here are the steps that I recommend (taken from the LexisNexis article):

  1. Close Word, Excel, Outlook and Time Matters
  2. Select all of this text, including quotes (triple-click on it to select all)
    cd "C:\Program Files\Microsoft Office 15\ClientX64"
  3. Press Ctrl-C or right-click | Copy to copy it.
  4. In the Search box by the Start button, type: cmd
  5. Right-click on Command Prompt
  6. Choose: Run As Administrator
  7. Right-click just after the command prompt and choose Paste.
  8. Press Enter
  9. Select all of this text, including quotes (triple-click on it to select all)
    officec2rclient.exe /update user updatetoversion=15.0.4745.1002
  10. Press Ctrl-C or right-click | Copy to copy it.
  11. Right-click just after the command prompt and choose Paste.
  12. Press Enter
  13. Wait for the update to finish.

Now your Time Matters links in Microsoft Office should work.
