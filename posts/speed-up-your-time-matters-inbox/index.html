Speed Up Your Time Matters Inbox

Date: Jul. 15, 2020    Categories: email

In the Personal Inbox, you can run the Clean Inbox utility speed up the Time Matters Personal Inbox dramatically. As the number of emails in the Inbox folders grows, the time it takes to open the Inbox can increase dramatically.

The Clean Inbox utility removes emails from being displayed in an Inbox folder. Instead, they will appear in the email list and on the email tabs of related Contacts and Matters.

The Clean Inbox utility works on tagged emails where a Regarding field (Client Name, Client Number, Matter Name, and/or Matter Number) contains data. For emails that do not have one of these fields filled, you need to complete one or more Regarding fields. You can open them individually or process multiple emails for the same Client and/or Matter at once. To do that, tag the emails for a particular Matter or Client and use the Set Regarding option to fill in one or more of the Regarding fields.

If you have a large number of emails that are not linked to any Client (Contact) or Matter, you can create a generic Contact or Matter, e.g. Inbox emails. Next you can tag those emails and use Set Regarding to link them to your generic Contact or Matter. That will allow you to use the Clean Inbox utility to get them out of the Personal Inbox folders and onto the email List.

The utility cleans tagged emails in the currently selected folder. The utility automatically clears the Show on Inbox check box and selects theShow on email List check box for each record. The tagged records are removed from the Inbox List and only appear in the email List.
Follow these steps to run the Clean Inbox utility:

  1. Select the Inbox folder.

  2. Tag the records you want to clean. (Records without a completed Regarding field can be tagged but they will be skipped.)

  3. Click Process on the Personal Inbox toolbar and choose Clean Inbox.
