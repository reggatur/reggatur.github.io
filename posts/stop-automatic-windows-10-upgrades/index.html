Stop Automatic Windows 10 Upgrades

Date: Aug. 9, 2016    Categories: Windows , upgrading

Sometimes Microsoft releases upgrades that are buggy, for example, the Windows 10 Anniversary Update. To avoid automatically applying future upgrades, follow the steps in this PDF file:

Windows 10 Stop Upgrades

It is important to keep Windows and other software up-to-date to avoid damage from viruses and hackers that exploit security holes. A best practice is to use settings that do this automatically.

The steps in the illustrated PDF guide allow you to defer the downloading and installation of Windows upgrades while still automatically applying Windows Security updates.
