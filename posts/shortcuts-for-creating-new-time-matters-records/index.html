Shortcuts for Creating New Time Matters Records

Date: Jul. 19, 2023    Categories: forms , related records

Time Matters has so many different ways of doing the same thing. It is easy to miss the fastest method.

For example, you can quickly create Supporting Records linked to a Contact or Matter. Supporting records include:

  • Billing

  • Document

  • email

  • Event

  • Mail

  • Note

  • Outline

  • Phone Call

  • ToDo

  • User-Defined

  • Web

For example, to create a new Note Record linked to a Contact, highlight the Contact record in the Contact list. Then click on File / New Record / Note.

When you do that, you see the list of other records that can be linked to the Contact. You also see the shortcut keys that save you even more time.

In the screenshot, above, you see the shortcut keys. You also see that you can link a new Matter to the Contact you highlighted.

Each time you added a new record linking it to a Contact or a Matter in this way, the new record inherits information from the linked Contact or Matter, a real time-saver!
