Time Matters 16.3 Recommended

Date: Dec. 13, 2017    Categories: updates , links

After a rocky series of earlier releases, I now recommend Time Matters 16 to most Time Matters client.

The current release is Time Matters 16.3.0.73. The significant limitations in Time Matters affect billing links to the latest versions of third-party billing software. Of course Billing Matters is built into Time Matters as an option, so Billing Matters is totally compatible.

Billing software versions supported by Time Matters 16.3:

  • PCLaw 16.1, 16, 15.5, 15.1, 15.0 (Limited), 14.x down through 11
  • QuickBooks 2017, 2016 Pro / Enterprise, 2012-2015 Pro / Enterprise
  • Timeslips 2017, 2016, 2015, 2014, 2013. 2012, 2011
  • Juris 2.8, 2.7x, 2.60 and up

Billing software versions NOT supported by Time Matters 16.3:

  • Tabs3 - all versions (import only from 15, 41, and 12)
  • Timeslips 2018
  • Timeslips Premium

Microsoft SQL Server versions supported by Time Matters 16.3:

  • Microsoft SQL Server 2016, 2014, 2014, 2008 R2, including free Express versions
  • No support yet for Microsoft SQL Server 2017 (though it may work)

Microsoft Windows versions supported by Time Matters 16.3:

  • Windows 10, 8.1, 8, 7 (excluding Starter)
  • Windows Server 2016, 2012 R2, 2012, 2011 SBS, 2008 R2, 2008, SBS
  • Virtual Servers (virtual machines)

Third party software links (TMSave) supported by Time Matters 16.3:

  • Adobe Acrobat and Reader DC, XI, X and 9
  • Microsoft Office 2016 CTR and non-CTR (click-to-run), including Word, Outlook, Excel
  • Microsoft Office 2013, 2010, and 2007 SP3 (limited support)
  • WordPerfect X7, X6, X5

Third party software links NOT supported by Time Matters 16.3:

  • Microsoft Office Home & Student, Starter, Personal, Trial and Office Online editions
  • Microsoft Office 64-Bit in Terminal Services (Remote Desktop) environment
  • WordPerfect X8
