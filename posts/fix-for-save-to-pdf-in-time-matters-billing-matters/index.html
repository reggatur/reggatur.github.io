Fix for Save to PDF in Time Matters / Billing Matters

Date: Apr. 18, 2021    Categories: Billing Matters , links , troubleshooting

Time Matters reports can be saved to PDF files. Billing Matters creates PDF copies of invoices that you produce.

For reasons that are unknown at this point, Time Matters 16.6 can lose the capability of printing to PDF. If that happens, you can still generate invoices with Billing Matters, but you won’t have electronic copies of them!

Here are the steps to fix this problem with saving or printing to PDF:

  1. Close Time Matters

  2. Open Windows File Explorer (the yellow folder icon)

  3. Go to: C:\Program Files (x86)\LexisNexis\Time Matters

  4. Double-click on Install.exe

  5. On the Taskbar or Desktop, right-click on the Time Matters icon.

1. If the Time Matters icon is on the Windows Taskbar, right-click Time Matters and select Run As Administrator. It won’t work without this step!

2. If the Time Matters icon is somewhere else, select Run As Administrator.

  1. Close and reopen Time Matters normally.

  2. Try saving a Report to a PDF file.

Now Time Matters printing should work properly. It needs to be working in order to save reports and invoices to PDF files.
