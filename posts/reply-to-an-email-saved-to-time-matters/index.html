Reply to an email Saved to Time Matters

Date: Feb. 15, 2019    Categories: email

Question: How can I reply to an email that was saved into Time Matters from Outlook?

You find the email in Outlook reply to it from within Outlook. That assumes you have set an option to save TM-Connected emails to a folder in Outlook. To set that option in Outlook:

File / Options / Add-ins

Click: LexisNexis Practice Management Integration / Add-ins Options

After saving email, move to: (optionally create a folder, such as TM, and select a folder)

That makes it easy to find the TM-connected emails and reply to them.

Alternatively, you might be able to set up your TM Inbox as a “Send Only” tool by creating a profile that connects to your SMTP (Simplified Mail Transport Protocol) server. Then you can reply to emails from within Time Matters and easily link them to the relevant Matters.

Another option is to find the email in Time Matters and use a Formattable Clipboard to copy it and then paste it into a new Outlook email. Here is my Formattable Clipboard:

________________________________________________________

{PRI EMA:DATE}  {PRI EMA:TIME}

To:{TAB}{PRI EMA:TO}{IF {PRI EMA:CC TO} ISNOTBLANK} {THEN}

CC: {PRI EMA:CC TO}{END IF}

From:{TAB}{PRI EMA:FROM}

{IF {PRI EMA:CLIENT} ISNOTBLANK} {THEN}Client:{TAB}{PRI EMA:CLIENT} // {PRI EMA:MATREF}

{END IF}Subject:{TAB}{PRI EMA:SUBJECT}{IF {PRI EMA:ATTACH} ISGREATER 0} {THEN}

{TAB}Attachment{END IF}

{PRI EMA:MEMO}

You should be able to paste the above text directly into a new, empty email Formattable Clipboard and use it with any version of Time Matters.
