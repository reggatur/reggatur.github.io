Introduction to Forms, custom fields and Form Styles

Forms are used to enter, view, and update information for each record type. Every Form contains a collection of fields that store the information for a Contact, Matter or other type of record.

While all Forms share many common fields, each record type also includes fields that are unique. Understanding what information is stored in these fields will make it easier to search for data, run reports, and use other features.

Each Form is organized into sections identified by Tabs across the top of the Form. The Primary, Secondary, and Additional Tabs contain both standard fields and user-defined fields.

User-defined fields can be customized to meet the needs of your firm and practice areas. Using Form Styles, you can also display different custom fields based on a record's Classification Code. For example, selecting the Personal Injury Classification Code can automatically display fields that are specific to personal injury matters.

Form Styles are configured by selecting File | Setup | Templates | Form Styles.
