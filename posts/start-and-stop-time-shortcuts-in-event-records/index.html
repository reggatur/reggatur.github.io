Start and Stop Time Shortcuts in Event Records

Date: Oct. 25, 2013    Categories: calendar

Updated 2014-02-20

Time Matters 13 now allows entry of an Event on the Calendar without having to enter a Stop Time. If no Stop Time is entered, the Stop Time defaults to the Start Time so the Event has a zero duration.

The shortcuts described below remain useful for entering Events since most will have different Start and Stop times.

Shortcuts for Entering Start, Stop and Duration in Event Records

In Time Matters 12 SP2, a Duration greater than 0 is required in Event records.

These shortcuts speed up the entry of Start and Stop Times or, alternatively, Start Times and Durations. If you enter Start and Stop Times,The Durations are filled automatically.

If you enter a Start Time and a Duration, the Stop Time is filled automatically.

Enter two numbers in the Time field. The time and duration are completed

If you need to enter any time from 7:00 pm to 11:00 pm, you need to type a "p" after the time number since 7 - 11 are set to am by default.

Examples:

Enter in Time field Result in Time field Result in Duration
9-10 9:00am- 10:00am 1.00
930-10 9:30am-10:00am 0.50
1-2 1:00pm-2:00pm 1.00
5-7p 5:00pm- 7:00pm 2.00 Note: You need to use the “p” for pm. Numbers 7 to 11 default to am

Or enter a Time and a Duration****

Enter in Time field Enter in Duration Results in Time Results in Duration
9 1 9:00am- 10:00am 1.00
930 .5 9:30am-10:00am 0.50
1 1 1:00pm-2:00pm 1.00
7p 2 7:00pm- 9:00pm 2.00
