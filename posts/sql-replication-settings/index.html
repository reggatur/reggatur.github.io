Synchronizing Time Matters between Two Offices

Date: Jan. 15, 2026    Categories: synchronization

Attorneys and staff located in offices in cities different other than your main office can have immediate access to your Time Matters data.

You can install Time Matters in the main office and remote offices. After setting up Microsoft SQL Server Replication, the records in the offices can be synchronized. Everyone sees the same records.

You may have more than one office in other cities and keep Time Matters synchronized in all of them.

In the background, Microsoft SQL Server keeps the offices up-to-date.

This PDF file, SQL Replication Settings, illustrates the setting for Microsoft SQL Server Replication.

You will want to employ an experienced Time Matters expert to set this up for you. Testing the service is important before you roll it out to multiple offices.
