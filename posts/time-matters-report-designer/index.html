Time Matters Report Designer

Date: Mar. 15, 2026    Categories: Reports

Time Matters has a full-featured Report Designer. You can create your own custom reports for Contacts, Documents, Events, Matters and Billing information. You select the records, fields, layout, sorting and totals that you need. This illustrated PDF guide shows how to create your own custom reports.

The sample report shows how to create a custom report that counts the number of Document records per Matter. The last steps show how to save the results to Excel where you can identify the Matters with the highest numbers of documents.
