Outlook Search Option - All Folders

Date: Apr. 3, 2014    Categories: MS Office , email

Do you spend time running the same search over and over in different Outlook folders, such as Inbox, Sent Items, and custom folders? If so, you are missing an option in MS Outlook that lets you search All Folders from the Search Box.

You can switch back and forth between searching the Current Folder and searching All Folders.

To switch search options:

  1. Click on Search Tab | Search Tools | Search Options
  2. In the Results panel, select: All Folders (or Current Folder to limit your search)
  3. Click OK

!\storage\images\1234tips\outlook-search-option.png

These steps work for both Outlook 2010 and 2013, but there is a handy drop-down by the Search Box in Outlook 2013 that lets you switch back and forth with few clicks.
