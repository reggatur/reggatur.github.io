Time Matters Error - Unable to Connect to SQL Server

Date: Feb. 28, 2020    Categories: troubleshooting , links , MS Office

Various issues can prevent Time Matters from connecting to SQL Server. Let’s look at one common cause.

Time Matters may occasionally stop working and freeze, especially older versions of Time Matters. When that happens, you will typically just reopen Time Matters and continue working, ignoring the message saying you are already logged in.

In that scenario, an invisible Time Matters process from your earlier Time Matters session may continue running. If that happens, the process named tmwe.exe is duplicated in Windows Task Manager. After multiple Time Matters freezes, you can end up with many copies of tmwe.exe running in Task Manager.

Now, if you try to use the TM Save button in MS Word or in another Office program, you may get this error message:

The text of the message is:

Time Matters has encountered an error. Please take the action indicated below. For additional assistance, contact Time Matters Technical Support.

Error Message Unable to Connect to SQL Server….

8 - Communication link failure

Recommended Action - Review Support Center article ID 61034 for instructions on diagnosing and resolving the problem.

Fix the Issue

  1. Close Time Matters

  2. Right-click on the Windows Toolbar.

  3. Click Task Manager

  4. Click Details

  5. Scroll down to tmwe.exe

  6. Click on tmwe.exe and press the End Task button (lower right).

  7. Repeat step 6 for each tmwe.exe that appears in Task Manager.
