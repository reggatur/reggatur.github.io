Documents Button on the Button Bar

Date: Sep. 23, 2021    Categories: lists , document management

The Time Matters Button Bar tends to be neglected. You can add some useful, time-saving buttons with just a few clicks.

One useful Time Matters button is the Documents Button. You can set it to show a list of frequently-used documents automatically, though it is up to you to code the Document records for your frequently-used list.

First, add the Documents button to the Button Bar:

  1. Right-click anywhere on the Main Toolbar (aka the Button Bar).

  2. Click Customize.

  3. Find Document List in the left panel and double-click it.

  4. Document List now appears at the bottom of the list of buttons in the right panel. Click on it.

  5. Click the Up button repeatedly to move the Document List button up the list. The higher it goes, the closer it will be to the left end of the Button Bar.

That may be as far as you want to go. You now can easily access a list of Document records in Time Matters and sort it by clicking the column labels.

You can stop right here! But if you are into heavy customization, there’s more.

If you would like easy access to a list of frequently-used Documents, create a FREQ Classification Code, code some frequently-used Documents, and add an Advanced Search:

  1. Go to Main Menu | File | Setup | Codes | Classification Codes

  2. Select Document from the drop-down.

  3. Click the Add button (green plus) and type FREQ as the Code. Press OK | Close.

  4. Back in the Document List, find records for Documents you want to appear on the list when you click the Document button. Know that you can easily clear that filter and search for other documents as needed.

  5. Add the Classification Code, FREQ, in the Code field of the records for your frequently-used Documents.

  6. Still in the Document List, go to Main Menu | Search | Advanced Search.

  7. Select Code in the Field column, Is Equal To in the Comparison column, and enter FREQ in the Compare To column.

  8. Press the Save button at the bottom of the window.

  9. Give this Advanced Search a name, such as FREQ. Press OK | OK.

Now you are ready to use the FREQ Advanced Search.

  1. In the Main Menu, go to: Main Menu | File | Setup | General | User Level

  2. Select Lists and choose Documents from the Select List Type drop-down.

  3. Click: Set List Options
    Just one more step!

  4. In the first field, Pre-Search Default Selection , choose your Advanced Search: FREQ (Adv).
