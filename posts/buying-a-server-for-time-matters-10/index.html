Buying a Server for Time Matters 10

Date: Oct. 11, 2009

You may not need a "real" server to run Time Matters 10. But you may need to buy a new computer, especially if you are upgrading from the Professional Edition of Time Matters. This article gives you information about your options and costs.

For One or a Few Users

You do not need a "real" server to run Time Matters 10 for one or a few users. A solo can run TM10 on a laptop. A better approach for a small office is to dedicate a PC as your file server and database server. For a small office you can use a PC running:

Windows XP, but we recommend moving to Windows 7 once it is approved for Time Matters 10.

As little as 1.5 GB of RAM, but the more RAM, the better.

2 GHz processor or faster

For a Small Office

For a small office of 3 to 9 users, you can go with either a real server running Microsoft server software or with a basic computer running MS Windows XP or Windows 7 (when Windows 7 is approved for Time Matters).

In either case, it is best to have 4 GB or more RAM on the Time Matters computer. RAM is inexpensive and well worth the cost and labor for an upgrade. When buying a computer, we recommend that it have 4 slots or more for RAM.

For Ten or More Users

With ten or more users, you need to have a Windows operating system on a dedicated server computer. Your server should be configured to handle the number of users in your office. We recommend that you get expert advice on setting up your server since it is so vital to the efficiency and operation of your business.
