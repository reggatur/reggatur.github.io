Document Form Folder Fields

Date: Mar. 15, 2024    Categories: document management , forms

You can customize the Time Matters document management system to specify Client and Matter field names that differ from the default choices: Contact Name and Matter Name.

The names of Clients and Matters can become quite long and contain special characters. That can cause issues with document folder names, resulting in file paths that exceed the Windows limit of 255 characters. Long folder names can also make navigation of the folders difficult, especially if you use multiple nested subfolders for various types of documents.

By created a custom Con Folder field in for Contact Form Styles and a custom Mat Folder field for Matter Form Styles, you can enter shorter, suitable folder names at the time that Contacts and Matters are added to Time Matters.

Field matching allows you to incorporate these folder names in Document records and in the AutoNaming convention used in Time Matters.
