Time Matters Calendar - Change the Field Order

Date: May. 15, 2026    Categories: Calendar

How to change the order in which fields are displayed in the various Time Matters Calendar views:

  1. Right-click on the heading of a Calendar record.
  2. Choose: Display Options (not shown below)
  3. Click on the tab for one of the Calendar views.
  4. Click the Select Fields button.
  5. Clic on one of the field names.
  6. Use the Up and Down buttons to position each field.
