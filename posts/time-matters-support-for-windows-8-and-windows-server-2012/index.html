Date: May. 15, 2013    Categories: Windows , updates

Update - Time Matters 12 Service Pack 2 Supports Windows 8

Please see our post on updating to Time Matters 12 Service Pack 2. More...

Support for Windows 8 Due in July 2013

Don't move to Windows 8 just yet if you are using Time Matters. LexisNexis plans to support Windows 8 in Time Matters 12 Service Pack 2 due for release in July 2013.

You can install Time Matters 12 on Windows 8, but links to other programs may prove to be problematic. For example, you may not be able to use Time Matters Merge Templates at all.

Support for Windows Server 2012 Due in Q4 2013

Don't buy a new server with Windows Server 2012 or upgrade an existing server to Windows Server 2012 until Q4 2013 if you want support from LexisNexis for Time Matters. We have successfully installed Time Matters 12 SP1 on Windows Server 2012, but LexisNexis will not be providing support until the release of Time Matters 13 due in the fourth quarter of 2013.
